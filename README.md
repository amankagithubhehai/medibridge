# MediBridge

A hospital network management system with referral tracking, patient management, and analytics.

## Tech Stack

- **Frontend:** React, Vite, React Router, Lucide Icons
- **Backend:** Node.js, Express, MongoDB (with in-memory fallback), JWT Auth

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
